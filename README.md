# MED System — sito demo

Questo repository contiene solo il **sito dimostrativo** di MED System
(https://titan-code-sm.github.io/Med-System-DEMO/): l'app aperta nel browser con
pazienti di esempio, senza account, e il pulsante **«Scarica il programma»**,
che funziona con la password generata nel portale (Sito demo → Download del
programma).

Tutto il resto (codice dell'app, PDF dei consensi, compilazione dei .exe e
release, funzioni Firebase, portale) sta in
[Gestione-MED-system](https://github.com/titan-code-sm/Gestione-MED-system).

I file di questo repository (`index.html`, dati demo, loghi, `consensi-pdf/`)
sono una **copia automatica** della cartella `app/` di Gestione-MED-system,
aggiornata ogni ora dal workflow «Aggiorna la demo» (o a mano da Actions →
Run workflow). Non modificarli qui: verrebbero sovrascritti.
